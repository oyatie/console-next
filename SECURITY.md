# Security

Report a vulnerability privately through [GitHub private vulnerability reporting for this
repository](https://github.com/oyatie/console-next/security/advisories/new). Do not open a
public issue, discussion or pull request about it.

We acknowledge a report within 3 business days and fix by severity. There is no bug bounty.

Please do not test against production systems or other people's data, and give us a reasonable
time to fix the issue before you disclose it.
